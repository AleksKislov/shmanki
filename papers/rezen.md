# Рецензия на выпускную квалификационную работу

**Тема:** Разработка обучающей платформы для разработчиков на основе модифицированного алгоритма интервального повторения с учётом иерархической структуры знаний

---

Выпускная квалификационная работа посвящена актуальной теме, связанной с разработкой адаптивной обучающей платформы для разработчиков программного обеспечения. Актуальность исследования обусловлена отсутствием систем, одновременно обеспечивающих автоматическую генерацию учебного контента, учёт иерархических зависимостей между учебными элементами и научно обоснованный алгоритм планирования повторений.

В ходе выполнения работы автором проведён анализ теоретических основ интервального повторения и существующих решений, разработана модель гетерогенного информационного объекта (инфо-граф), предложен модифицированный алгоритм FSRS с коэффициентом иерархической поддержки и эффективной сложностью карточки, реализовано полнофункциональное веб-приложение на Go, Qwik и PostgreSQL. Представленные результаты свидетельствуют о достижении цели исследования и подтверждают достаточный уровень подготовки автора.

Вместе с тем к работе имеются отдельные замечания:
- апробация ограничена одним предметным доменом; систематическая количественная оценка преимуществ предложенного алгоритма по сравнению с базовым FSRS не представлена;
- значения ключевых гиперпараметров алгоритма выбраны без экспериментального обоснования.

Указанные замечания носят частный характер и не снижают общей ценности выполненной работы.
